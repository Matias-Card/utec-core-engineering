# Manejo de archivos

Este proyecto contiene ejercicios de Python para leer y gestionar archivos de texto utilizando correctamente los recursos de archivo.

0-read_file: lee un archivo de texto UTF-8 con la sentencia with e imprime todo su contenido en la salida estándar.

1-write_file: escribe una cadena de texto en un archivo UTF-8 utilizando with, sobrescribe el contenido existente y devuelve el número de caracteres escritos.
