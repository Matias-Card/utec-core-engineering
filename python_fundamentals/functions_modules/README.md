# Functions and Modules

This directory contains Python exercises about functions and modules.

## Exercises

- `islower.py`: Checks whether a character is a lowercase ASCII letter.
- `uppercase.py`: Converts lowercase ASCII letters to uppercase.
- `print_last_digit.py`: Prints and returns the last digit of a number.
- `pow.py`: Calculates a number raised to a power.
- `simple_add.py`: Demonstrates function execution and module imports.
- `test_import.py`: Tests importing a Python module.
- `add_0.py`: Defines the addition function.
- `add.py`: Imports and uses the addition function.

## Requirements

- Python 3
- Executable Python scripts
- PEP 8 style conventions
- No unnecessary execution when importing modules
