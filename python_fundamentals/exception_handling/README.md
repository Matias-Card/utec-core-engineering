# Manejo de excepciones

Este proyecto contiene ejercicios de Python para gestionar errores durante la ejecución de programas mediante excepciones, controlar entradas inválidas y garantizar un comportamiento seguro y predecible.

0-safe_print_list: imprime hasta x elementos de una lista en una sola línea, gestiona índices inexistentes mediante excepciones y devuelve el número real de elementos impresos.

1-safe_print_integer: imprime un valor con el formato de entero decimal, devuelve True si la impresión tiene éxito y False si se produce un error de formato o tipo.

2-safe_print_list_integers: imprime los primeros x elementos enteros de una lista, omite los elementos que no son enteros, gestiona los tipos de datos mediante excepciones y devuelve la cantidad de enteros impresos.

3-safe_print_division: divide dos valores dentro de un bloque try, gestiona errores asignando None al resultado, imprime el resultado en finally y devuelve el resultado de la división o None.
4-raise_exception: lanza explícitamente una excepción TypeError mediante la instrucción raise.
