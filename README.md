# UTEC Core Engineering

## Fundamentos de Python

Este repositorio contiene ejercicios prácticos para aprender los fundamentos de Python.

### Flujo de control

El directorio `python_fundamentals/control_flow/` contiene ejercicios sobre estructuras condicionales, operadores de comparación, lógica booleana y bucles.

#### Tarea 0: Positivo o negativo

El archivo `positive_or_negative.py` genera un número entero aleatorio entre -10 y 10 e indica si el número es positivo, negativo o cero.
