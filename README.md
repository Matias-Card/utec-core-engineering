# Herencia y polimorfismo

Este proyecto contiene ejercicios de Python para comprender la herencia y el polimorfismo mediante la creación de clases relacionadas, reutilización de métodos y sobrescritura de comportamientos.

##0-polymorphism_demo: crea una clase padre `Animal` y dos clases hijas `Dog` y `Cat`, sobrescribe el método `speak()` para obtener diferentes sonidos, demuestra el polimorfismo mediante una lista de objetos y comprueba las relaciones entre clases e instancias utilizando `isinstance()` e `issubclass()`.

##1-base_geometry: crea la clase `BaseGeometry` con el método `area()`, que lanza una excepción cuando el cálculo no está implementado, y el método `integer_validator()`, que comprueba que los valores sean enteros positivos y genera excepciones cuando los datos no son válidos.
